## How to use

1. Fill in your license details in the table above.
2. Work the checklist for each month. Mark boxes when done.
3. Use the renewal month card for submission steps; start 60-90 days early.
4. File the printed calendar with your CE tracker and certificates.

## Renewal submission checklist

- [ ] Renewal application completed and signed
- [ ] CE hours total meets state requirement
- [ ] Category-specific hours met (e.g. pharmacology)
- [ ] Copies of all certificates attached
- [ ] Renewal fee paid
- [ ] Submission confirmation saved
- [ ] Renewed license received and on file

**Renewal month tip:** if your license expires in a specific month, move the submission checklist into that month and start 60-90 days early.
