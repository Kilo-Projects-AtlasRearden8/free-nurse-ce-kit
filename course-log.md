## Instructions

1. Use one row per completed course or activity.
2. Record the certificate number and keep the certificate in your CE folder.
3. Save course URLs or access info in case you need to re-download a certificate.
4. Pair each course with a reflection template (`reflection-templates.md`) and file them together.
