License Renewal Calendar

Education only. This calendar is for personal renewal planning. It is not medical advice, nursing advice, or licensure guidance. Renewal deadlines, grace periods, CE categories, and fees vary by state — always confirm dates and requirements with your state board of nursing.

How to use

  1. Fill in your license details in the card above.
  2. Work the checklist for each month. Mark boxes when done.
  3. Use the renewal month card for submission steps; start early so nothing is late.
  4. File the printed calendar with your CE tracker and certificates.

12-month renewal planner

January

This month's focus:
  • Review this year's CE hour requirements
  • Check hours completed vs. hours needed
  • Register for any needed courses
  • File new certificates

February

This month's focus:
  • Continue CE coursework
  • Track hours in CE tracker
  • File new certificates
  • Confirm in-person/webinar dates

March

This month's focus:
  • Mid-year CE progress check
  • Complete outstanding courses
  • File new certificates
  • Update CE tracker totals

April

This month's focus:
  • Complete remaining coursework
  • File new certificates
  • Update CE tracker totals
  • Note any category gaps

May

This month's focus:
  • Finish all CE hours
  • Verify every certificate is filed
  • Start renewal application draft
  • Confirm license expiration date

June

This month's focus:
  • Finalize renewal application
  • Gather supporting documents
  • Calculate total renewal cost
  • Schedule submission date

July

This month's focus:
  • Submit renewal application
  • Pay renewal fee
  • Save submission confirmation
  • Set reminder to check status

August

This month's focus:
  • Check renewal application status
  • Respond to any board requests
  • Save renewed license document
  • Update license expiration date

September

This month's focus:
  • Confirm renewed license on file with employer
  • Start next reporting period CE log
  • File this year's renewal calendar
  • Note next year's expiration

October

This month's focus:
  • Register for upcoming courses
  • Track new CE hours
  • File new certificates
  • Check for board rule changes

November

This month's focus:
  • Complete scheduled coursework
  • File new certificates
  • Update CE tracker totals
  • Review hours remaining

December

This month's focus:
  • Finish all CE hours for the period
  • Verify all certificates filed
  • Confirm totals meet requirements
  • Prepare next year's calendar

Renewal submission checklist

  • Renewal application completed and signed
  • CE hours total meets state requirement
  • Category-specific hours (e.g. pharmacology) met
  • Copies of all certificates attached
  • Renewal fee paid
  • Submission confirmation saved
  • Renewed license received and on file

Renewal month tip: if your license expires in a specific month, shift the "Renewal submission checklist" into that month's card and start 60-90 days early.
